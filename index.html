ModFolio

Create: Deep Seas

Create deep seas is a mod that adds full submarine functionality to minecraft including but not limited to : a fully function finite element analysis system to calculate accurate hull pressure distribution , procedurally generated accurate ocean terrain with simulated tectonic boundries and plate shift using voronoi cells .The mod is split into 2 main parts , create submarine that deals with all the aspects of a submarine like the hull controller, the hermetic seal , fog controller among other things; the second part is the abyss , a new dimension over 1000 blocks deep yet generates faster than regular minecraft. It uses accurate plate tectonics to generate abberations at plate boundries for more realism.

GitHub: Create: Deep Seas

Angry Birds Epic: All Stars

Angry birds all stars is the most popular angry birds epic mod with a discord server of over 40k people and is the go to mod to play angry birds epic hassle free. Fluid Sim (Rust)

A fluid simulation written in Rust.Just an excercise to learn a new language but it performs excellent even at 1080p where other fluid sims might not. The original code now runs 1:1 in the browser via WebAssembly, with all the modes (1-7) at a scaled-down resolution - the GPU pipelines are skipped since browsers can't use them, everything falls back to the CPU sims. Game of Life Simulator

A Conway's Game of Life simulator. Able to run up to 4 million cells at a decent 24 generations per second with features to analyse still forms , methelbauhs and even the occurence frequencies across runs. It also incorporates a new file type (.gol) that preserves data from incredibly long runs to be analysed later or started from that point. The original code is actually written in c++ as you can see (here) i did not recreate this in javascript i compiled it to a wasm so i can run 1:1 the exact code in the browser
